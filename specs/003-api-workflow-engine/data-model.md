# Data Model: API Workflow Engine

**Branch**: `003-api-workflow-engine`

---

## Entities

### Workflow

The top-level definition of a named multi-step API automation flow.

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `workflowId` | String | Yes | Format: `wf-{8hex}`, generated by `Ids` |
| `name` | String | Yes | User-supplied display name |
| `description` | String | No | Optional human-readable description |
| `baseUrl` | String | No | Overrides per-step base URL if set |
| `variables` | `Map<String, String>` | No | Workflow-level variables, resolved as `{{key}}` |
| `steps` | `List<WorkflowStep>` | Yes | Ordered; minimum 1 step |
| `createdAt` | Instant | Yes | Set at creation |
| `updatedAt` | Instant | Yes | Updated on every save |
| `status` | String | Yes | `active` \| `archived` |

**Validation**: `steps` must not be empty. `name` must not be blank. Circular variable references (step X references step X's own extraction) must be rejected at save time.

---

### WorkflowStep

One API call within a workflow. Steps are executed in list order.

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `stepId` | String | Yes | Format: `step-{8hex}`, unique within the workflow |
| `name` | String | Yes | User-supplied label (e.g. "Login", "Get Profile") |
| `method` | String | Yes | HTTP verb: GET \| POST \| PUT \| PATCH \| DELETE |
| `path` | String | Yes | Path relative to base URL, supports `{{varName}}` |
| `headers` | `Map<String, String>` | No | Static and `{{varName}}` values |
| `body` | String | No | JSON string, supports `{{varName}}`. Null for GET/HEAD/DELETE. |
| `queryParams` | `Map<String, String>` | No | Static and `{{varName}}` values |
| `timeoutMs` | Integer | No | Default 10000 |
| `extractions` | `List<ExtractionRule>` | No | Values to extract from this step's response |
| `injections` | `List<InjectionRule>` | No | Variables to inject into this step's request |
| `conditions` | `List<Condition>` | No | Pre-execution conditions evaluated against prior step |
| `haltOnConditionFailure` | Boolean | No | Default `false` (skip step); `true` = halt entire workflow |

---

### ExtractionRule

Extracts a named value from a step's response for use in subsequent steps.

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `variableName` | String | Yes | Name used in context: `step{N}.{variableName}` |
| `source` | ExtractionSource | Yes | `BODY` \| `HEADER` \| `STATUS` |
| `locator` | String | Conditional | JSONPath (for BODY, e.g. `$.data.token`) or header name (for HEADER). Not used for STATUS. |
| `secret` | Boolean | No | Default `false`; `true` masks value in results |

**Variable naming convention**: Variables are scoped to the step that extracted them. When referenced in later steps, use `{{step1.authToken}}`, `{{step2.resourceId}}`, etc. Workflow-level variables use `{{variableName}}` without a step prefix.

---

### InjectionRule

Injects a resolved variable into a specific location of this step's outgoing request.

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `target` | InjectionTarget | Yes | `HEADER` \| `BODY_FIELD` \| `QUERY_PARAM` \| `PATH` |
| `targetKey` | String | Yes | Header name, JSON body field path, query param name, or path param name |
| `variableRef` | String | Yes | Variable reference, e.g. `{{step1.authToken}}` or `{{testMobile}}` |

---

### Condition

A predicate evaluated before a step executes, based on a prior step's response.

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `sourceStepId` | String | Yes | The step whose response is evaluated |
| `source` | ConditionSource | Yes | `STATUS` \| `BODY` \| `HEADER` |
| `locator` | String | Conditional | JSONPath or header name; not used for STATUS |
| `operator` | ConditionOperator | Yes | `EQ` \| `NE` \| `CONTAINS` \| `EXISTS` \| `EMPTY` \| `LT_STATUS` |
| `expectedValue` | String | Conditional | Not used for EXISTS/EMPTY operators |

**State transitions**:
- Condition met → step executes normally
- Condition not met, `haltOnConditionFailure=false` → step status = `SKIPPED`
- Condition not met, `haltOnConditionFailure=true` → step status = `SKIPPED`, all subsequent steps = `SKIPPED`, run status = `FAILED`

---

### WorkflowRun

The result of executing a workflow once.

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `workflowRunId` | String | Yes | Format: `wfrun-{8hex}` |
| `workflowId` | String | Yes | FK to Workflow |
| `workflowName` | String | Yes | Snapshot at execution time |
| `startedAt` | Instant | Yes | |
| `finishedAt` | Instant | Yes | |
| `status` | String | Yes | `passed` \| `failed` \| `partial` \| `error` |
| `stepResults` | `List<StepResult>` | Yes | In execution order |

**Status rules**:
- `passed`: all steps pass
- `failed`: one or more steps fail OR a halt condition triggered
- `partial`: one or more steps skipped but no halt; remaining steps passed
- `error`: unrecoverable exception during execution

---

### StepResult

The execution result of one workflow step.

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `stepId` | String | Yes | |
| `stepName` | String | Yes | Snapshot at execution time |
| `status` | String | Yes | `pass` \| `fail` \| `skipped` \| `error` |
| `requestSent` | RequestSnapshot | No | Method, resolved URL, headers, body (masked if secret) |
| `httpStatus` | Integer | No | Actual response code |
| `responseBody` | String | No | Truncated to 500 chars; masked fields replaced with `****` |
| `responseTimeMs` | Long | No | |
| `extractedValues` | `Map<String, String>` | No | Variable name → value (masked if secret) |
| `conditionResults` | `List<ConditionResult>` | No | Per-condition evaluation detail |
| `failureReason` | String | No | Human-readable explanation if status is fail/error/skipped |

---

### RequestSnapshot

Immutable snapshot of the outgoing request as sent (all variables resolved).

| Field | Type |
|-------|------|
| `method` | String |
| `url` | String |
| `headers` | `Map<String, String>` |
| `body` | String |

---

### ConditionResult

Per-condition evaluation detail stored in StepResult.

| Field | Type |
|-------|------|
| `conditionIndex` | Integer |
| `operator` | String |
| `actualValue` | String |
| `expectedValue` | String |
| `passed` | Boolean |

## Variable Scope Rules

| Variable type | Syntax | Available in |
|--------------|--------|--------------|
| Workflow-level | `{{myVar}}` | All steps |
| Step extraction | `{{step1.token}}` | Steps after step 1 |
| Global auth (from AuthConfig) | Auto-applied | All steps |

**Resolution order**: Per-step extraction variables override workflow-level variables of the same name.
