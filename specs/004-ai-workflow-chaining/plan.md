# Implementation Plan: AI-Driven API Workflow Chaining

**Branch**: `004-ai-workflow-chaining` | **Date**: 2026-08-07 | **Spec**: [spec.md](spec.md)

## Summary

Add an AI-powered workflow chaining feature to the existing API Test Agent. Users select an ordered list of API endpoints from an already-ingested spec. When the workflow runs, the LLM receives each step's response and the next step's endpoint definition from the spec, then determines the appropriate field values to inject — no manual extraction/injection rules required.

## Technical Context

**Language/Version**: Java 21, Spring Boot 3.3.2

**Primary Dependencies**: Spring AI `ChatClient` (existing, Anthropic Claude), Spring WebFlux `WebClient` (existing), Jackson ObjectMapper (existing)

**Storage**: File-based JSON in `data/ai-workflows/` and `data/ai-workflow-runs/` — same pattern as all existing stores

**Testing**: JUnit 5 + Spring Boot Test (existing `application-test.yml`)

**Target Platform**: Web application, embedded Tomcat 10.1.26, port 8080

**Performance Goals**: ≤10s per step (including LLM call); ≤60s for a 5-step workflow

**Constraints**: No new frameworks. Must not modify existing manual workflow (003) or plan generation features.

**Scale/Scope**: Supports workflows of up to 20 steps; desktop browser primary target.
